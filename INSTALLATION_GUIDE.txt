STEP 1: INSTALL MONGODB
================================================================================

Option A: MongoDB Community Server
1. Download: https://www.mongodb.com/try/download/community
2. Install with default settings
3. MongoDB will run automatically as a Windows service

Option B: MongoDB Compass (GUI Tool)
1. Download: https://www.mongodb.com/try/download/compass
2. Install and open
3. Connect to: mongodb://localhost:27017

VERIFY MongoDB is running:

================================================================================
WEBCAM FIX DETAILS
================================================================================

PROBLEM: Warnings auto-incrementing with proper face detection

SOLUTION APPLIED:
1. Frontend (WebcamProctoring.jsx):
   - More lenient face detection (skinToneRatio > 0.02)
   - Only report violations with VERY high confidence (0.95)

2. Backend (proctoring_service.py):
   - Stricter confidence filter (must be ≥ 0.85)
   - Only process very confident violations

RESULT:
✓ Normal face → No warnings
✓ Minor movements → Ignored
✓ Real violations (>1s) → Still detected correctly

================================================================================
TROUBLESHOOTING
================================================================================

MongoDB Connection Failed:
> Check if MongoDB service is running
> Reinstall MongoDB Community Server
> Check connection string in database.py

PDF Generation Error:
> pip install reportlab pillow
> Check write permissions in backend/reports/

Webcam Auto-Increment:
> Clear browser cache
> Restart frontend: npm run dev
> Check confidence values in browser console
> Adjust thresholds in WebcamProctoring.jsx if needed

Backend Won't Start:
> Check all dependencies installed
> Check port 8000 is not in use
> Check .env file has GROQ_API_KEY

Frontend Won't Start:
> npm install (in frontend folder)
> Check port 5173 is not in use
